# Generated maps

This directory is the local output surface for deterministic projections generated from canonical node metadata under `knowledge/`.

`catalogue.json` and `edition.json` are build artifacts. They are intentionally ignored and regenerated by `tooling/build_catalogue.py`; they are not canonical source and must not be edited or committed by hand.

Validation should prove that repeated builds from the same canonical tree and edition SHA are byte-identical.
