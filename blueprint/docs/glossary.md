# Glossary

Status: Specified only / roadmap

Shared vocabulary for the project. These definitions are reader-facing
summaries; canonical specifications and data contracts take precedence.

## Cognitive exocortex

The non-normative architecture metaphor for Goni's governed digital memory and
active cognitive layer operating around, but subordinate to, the human
principal. It complements Goni's product identity as a delegation OS and
bounded digital representative. See the
[Cognitive Exocortex Model](/blueprint/20-system/60-cognitive-exocortex-model.md).

## Digital meninges

A cross-cutting metaphor for the protections around Goni's digital cognition:

- **Dura:** hard security controls such as identity, secrets isolation,
  sandboxing, storage protection, and network egress policy.
- **Arachnoid:** controlled movement of context and commands through Work
  Orders, capabilities, scheduling, isolation, and budgets.
- **Pia:** provenance and epistemic controls attached to evidence, claims,
  memory, and receipts.

These names do not define new services or trust boundaries.

## First brain

The human principal. The first brain supplies goals, values, delegated
authority, final judgement, correction, and veto. It may establish bounded,
revocable autonomy corridors rather than approving every low-risk operation.

## Human sovereignty

The principle that Goni receives authority from the human principal and does
not own the principal's goals or values. Authority remains bounded, inspectable,
revocable, and subject to correction and veto.

## Second brain

The reader-facing name for Goni's durable memory responsibilities: governed
evidence plus episodic, semantic, procedural, relational, project, and policy
memory. It maps to the Vault and existing Knowledge/Memory contracts; it is not
an additional canonical plane. Working context is not part of durable memory
unless a separate memory grant authorizes consolidation.

## Third brain

The reader-facing name for Goni's active, bounded cognitive responsibilities:
perception, association, retrieval, context assembly, planning, verification,
and action preparation. It maps across the Harness, Context, Control, and
Execution responsibilities and does not own canonical memory, identity, policy,
permissions, approvals, or receipts.
