# Source claim: agent memory is distinct from RAG and has lifecycle dynamics

Hu et al. separate agent memory from retrieval-augmented generation and context engineering, then describe memory through its forms, functions, and evolution over time.

For Goni, the important consequence is that durable memory, current context, retrieval, task state, and an agent's current beliefs should not be collapsed into one chat-history abstraction.
