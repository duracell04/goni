# Canonical knowledge

This directory is the only canonical home for GONI knowledge nodes. Every Markdown file below it is independently addressable by a permanent ID and validates against `schema/node.schema.json`.

The repository describes a blueprint and architectural plan. A specification is not evidence that a mechanism exists. `implementation_state` is factual and independent from editorial `status`; migrated design nodes use `specified_only` unless repository-and-commit-pinned evidence supports a stronger value.

Large explanatory documents are syntheses. They introduce context and link to atomic nodes rather than repeating their normative propositions.
